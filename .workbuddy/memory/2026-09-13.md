## CNBizAPI 接入调研（用户问「怎么配置」）

**结论：服务真实存在，但现在直接配 Key 也跑不通，有三个硬问题。**

服务实况（实测 api.cnbizapi.com）：
- ChinaBiz MCP API v1.0.0，REST API + MCP Server，7700 万+企业记录，每日更新
- 注册：邮箱 + 密码 → `POST /v1/auth/register`（官网 "Get Free API Key"），立即拿 Key，无需绑卡
- 免费额度：**200 次/月**；付费低至 $0.057/次，全量画像 $0.30，1000 次批量 $75
- 鉴权：`Authorization: Bearer <API_KEY>`
- 数据来源自称 "registry-derived and commercially normalized" → 属**二手商业渠道**，非官方直连

真实接口（与代码不符）：
```
GET /v1/company/search?keyword=腾讯        ← 代码写成 POST /v1/company/search {keyword,limit}
GET /v1/company/basic?q=腾讯科技(深圳)有限公司  ← 代码写成 POST {credit_code}
GET /v1/company/shareholders?q=...        ← 代码写成 POST {credit_code}
GET /v1/company/{verify,executives,investments,branches,changes,ip-pledge,legal-risks,annual-report,full}
```

三个坑：
1. **TLS 证书已过期**（`certificate verify failed: certificate has expired`）→ httpx 默认校验连不上，需放宽校验或等对方续证
2. **接口形式不匹配** → `domestic/cnbiz.py` 三处调用必须改写（POST→GET、credit_code→q）
3. **计费错配** → 穿透核心的 `get_shareholders` 是**付费**工具（1 积分/次），
   免费 200 次只覆盖 free tier（search/basic/verify）；一家企业完整穿透约需 4~8 次股东查询

配额明细（/v1/tools）：free=search_company/get_company_basic/verify_company；
paid=get_shareholders(1)/executives(1)/investments(1)/branches(1)/changes(1)/ip_pledge(2)/legal_risks(4)/annual_report(4)/full(8)
