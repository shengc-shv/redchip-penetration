### 关键决策与踩坑

1. **方案文档指定的 `ah-disclosure-kit` 在 PyPI 上不存在**（`pypi.org/simple/ah-disclosure-kit/` 返回 404，
   pip 报 "No matching distribution found"）。港股抓取层改为**自研 HKEXnews 客户端**，接口链路：
   `/search/prefix.do`（代码→stockId，实测 00700→7609）→ `/search/titleSearchServlet.do`（JSON，
   `result` 字段是二次 JSON 字符串，`DATE_TIME` 为 DD/MM/YYYY）→ PDF 下载 → pypdf 分页。
2. **中文子串检索**：FTS5 默认 unicode61 切不出中文子串，改用 `tokenize='trigram'`（SQLite 3.50.4 可用）；
   trigram 要求 ≥3 字符，短词回退 `LIKE`。
3. **PNG 渲染**：本地 `brew install graphviz` 被沙箱拦截。渲染层改三级降级：
   PNG(dot) → 零依赖自绘 SVG → DOT/Mermaid，无 dot 也不中断。Actions 里用 apt 装 graphviz 出 PNG。
4. **Pydantic 陷阱**：`list.append(dict)` 不会触发校验，导致后续 `w.name` 报 AttributeError。
   解决：`LlmAOutput` 加 `model_validator(mode="before")` 把嵌套 dict 归一化为模型。
5. **公司名抽取噪声**：正则「…有限公司」会把叙述句（"本公司为一家于开曼群岛注册成立的获豁免有限公司"）
   和前缀污染（"向深圳市…"、"与深圳市…"）当成公司名。修法：工商候选名优先全词匹配，
   正则结果剔除停用词 + 剔除「已知名的加长变体」+ 长度 ≤20。
6. 时区收敛：ruff 查出 `datetime.now()` 无时区，已在 `config.py` 定义单一常量
   `CST = ZoneInfo("Asia/Shanghai")`，全项目引用。
